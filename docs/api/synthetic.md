# Synthetic generation

Reproducible illustrative datasets.

!!! danger "Illustrative data only"
    Generated curves are closed-form shapes — **not** Lamm-equation solutions,
    **not** simulations of sedimentation, and carrying no physical parameters.
    Nothing scientific may be inferred from them. See
    [Synthetic data](../concepts/synthetic-data.md).
